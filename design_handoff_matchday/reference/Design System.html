Design system

One restrained ladder for type, spacing, icons, radii and components — so every screen reads as the same calm, intuitive app. Hierarchy comes from weight and whitespace, not big type. This is the ruler; approve it and I measure every surface to it.

03

Spacing & layout

4px base grid

Scale (multiples of 4)

Rules
  • 18px side gutter on every screen — edges line up tab to tab.
  • 12px gap between stacked cards.
  • 14px padding inside cards; 11–13px inside list rows.
  • Screen content starts 24px below the header.
  • Bottom nav 62px; leave 84px bottom padding so content clears it.
04

Radii

three steps, no in-betweens

12controls · inputs · buttons
16cards · sheets · panels
999pills · avatars · crests*

*Team crests use 12px (rounded square); player avatars use 999 (round) — that shape difference is how you tell a team from a person at a glance. Drop the old 14 / 20 radii.

05

Icons

line · 1.9 stroke · round caps

Three sizes only: 16 in chips/dense rows · 18 inline & list rows · 20 in the bottom nav. One stroke weight (1.9). No filled icons except the active nav tile glyph.
